# Cover Flow WebGL2

The same Cover Flow scene rendered through WebGL2: projective album covers, bilinear sampling, antialiased edges, lighting, reflections, and spring easing at the same 720x480 output size.

Controls:

- Drag left/right: move through albums with inertia
- Tap an album: select it
- Keyboard: `Left/Right` or `A/D`
